# Arduino AI Assistant — ผู้ช่วย AI สำหรับเรียนไมโครคอนโทรลเลอร์

**เวอร์ชัน 2.7.1 (28 ก.ย. 2569)**

โปรแกรมรับคำสั่งภาษาไทย แล้วสร้างโค้ด **MicroPython** ให้บอร์ด ESP32, Raspberry Pi Pico และ Arduino รุ่นที่รองรับ
(ส่วน Arduino Uno / Nano / Mega จะได้โค้ด C++ แทน เพราะชิปเล็กเกินกว่าจะรัน Python)
พร้อม **ภาพเคลื่อนไหวการต่อวงจร** และ **ภาพการทำงานแบบเรียลไทม์**

## 1. ติดตั้ง (ทำครั้งเดียว)

1. ติดตั้ง Python 3.10 ขึ้นไปจาก python.org (ติ๊ก "Add Python to PATH" ตอนติดตั้ง)
2. ดับเบิลคลิก `install.bat` (หรือพิมพ์ `pip install -r requirements.txt`)
3. ดับเบิลคลิก `run.bat` (หรือพิมพ์ `python app.py`) เพื่อเปิดโปรแกรม

### ถ้าขึ้น Error ว่า "Non-ASCII character ... no encoding declared"

แปลว่าเครื่องมี Python 2 รุ่นเก่า ให้ติดตั้ง Python 3 เพิ่ม (ไม่ต้องลบ Python 2) ไฟล์ `run.bat` จะเลือก Python 3 ให้เอง
ถ้าพิมพ์คำสั่งเอง ให้ใช้ `py -3 app.py` แทน `python app.py`

## 2. ลง MicroPython ในบอร์ด (ทำครั้งเดียวต่อบอร์ด)

**วิธีง่ายที่สุด:** เลือกรุ่นบอร์ดและพอร์ต → แท็บผู้ช่วยนำทาง ขั้นที่ 1 → กดปุ่ม **"⬇ ลง MicroPython"**
โปรแกรมจะดาวน์โหลดเฟิร์มแวร์รุ่นล่าสุดจาก micropython.org และบอกบนจอว่าต้องกดปุ่มตอนไหน

- **ESP32 / ESP32-S3 / ESP32-C3 / ESP8266 / KidBright32 / ESP32-CAM:** เมื่อกรอบข้อความเปลี่ยนเป็น**สีส้ม** ให้กดปุ่ม **BOOT** ค้างไว้ จนเป็น**สีเขียว**จึงปล่อย (โค้ดเดิมในบอร์ดจะถูกลบ)
- **Raspberry Pi Pico / Pico W / Pico 2:** ถอดสาย กดปุ่ม **BOOTSEL** ค้าง เสียบสายกลับแล้วปล่อย โปรแกรมจะคัดลอกไฟล์ .uf2 ให้เอง
- ไฟล์ที่ดาวน์โหลดแล้วเก็บในโฟลเดอร์ `firmware/` ห้องที่ไม่มีอินเทอร์เน็ต ให้คัดลอกโฟลเดอร์นี้จากเครื่องที่โหลดแล้ว หรือกด "ใช้ไฟล์ในเครื่อง"
- ถ้าไม่สำเร็จ โปรแกรมจะบอกสาเหตุเป็นภาษาไทย (ยังไม่เข้าโหมด BOOT, พอร์ตถูกใช้อยู่, เลือกรุ่นบอร์ดผิด) และลองใหม่ด้วยความเร็วต่ำลงให้เองถ้าสายไม่ดี
- วิธีเดิมยังใช้ได้: Thonny → Tools → Options → Interpreter → "Install or update MicroPython"
- **Arduino Nano ESP32 / Nano RP2040 Connect:** ใช้ Arduino MicroPython Installer
- หลังลงเฟิร์มแวร์แล้ว ปิด Thonny ก่อนใช้โปรแกรมนี้ (ใช้พอร์ตพร้อมกันไม่ได้)

## 3. วิธีใช้

เปิดโปรแกรมแล้วจะเจอแท็บ **🧭 ผู้ช่วยนำทาง** ก่อน ทำตาม 6 ขั้นได้เลย:

1. **เชื่อมต่อบอร์ด** — เสียบ USB แล้วกด "ตรวจบอร์ด" โปรแกรมบอกรุ่นชิป เฟิร์มแวร์ และอุปกรณ์ I2C (เช่นจอ OLED) ที่ต่ออยู่
2. **อยากทำอะไร** — เลือกจากคลังโปรเจกต์ 66 แบบ (กรองตามหมวดและระดับได้) หรือพิมพ์เอง หรือกด "ให้ AI ช่วยคิด"
3. **เตรียมอุปกรณ์** — รายการของที่ต้องใช้พร้อมรูป และอุปกรณ์เสริมเช่นตัวต้านทาน
4. **ต่อสายทีละเส้น** — ดูแอนิเมชันทีละเส้น ต่อตามแล้วกดยืนยันเส้นต่อไป เส้นปัจจุบันจะหนาเป็นพิเศษ
5. **ตรวจการต่อสาย** — โปรแกรมส่งโค้ดทดสอบสั้น ๆ ไปรันบนบอร์ดจริงทีละอุปกรณ์ บอกว่าผ่านหรือไม่ผ่าน พร้อมสาเหตุเป็นภาษาไทย
6. **เขียนโค้ดและรัน** — ได้โค้ด MicroPython รันบนบอร์ดจริง แล้วดูกราฟและภาพการทำงานแบบเรียลไทม์

แท็บอื่น ๆ:

| แท็บ | ทำอะไร |
|---|---|
| ① สร้างโค้ด | พิมพ์คำสั่งภาษาไทย กดสร้างโค้ด ดูการต่อสายและคำเตือน กดรันหรืออัปโหลดลงบอร์ด **เปิดไฟล์โค้ด .py / .ino / .c (Turbo C) ของตัวเอง พร้อม 🩺 ตรวจจุดที่มักเขียนผิด** และ **เก็บโค้ดไว้ในคลังโค้ดของฉัน** ได้ ปุ่ม **📚 ตัวอย่าง Arduino** เปิดตัวอย่าง 127 แบบ (ดูข้อ 8-11, 14 และ 15) |
| ② ภาพวงจร / การทำงาน | **🔌 ภาพการต่อสาย**: ดูสายค่อย ๆ ต่อทีละเส้นพร้อมคำบรรยาย มีรูปวาดของอุปกรณ์ **🎞 ภาพการทำงานของโครงงาน**: เซนเซอร์วัดอะไร → บอร์ดตัดสินใจอย่างไร → อุปกรณ์ทำอะไร แบบเคลื่อนไหว (ดูข้อ 13) |
| ③ ข้อมูลเรียลไทม์ | กราฟและตัวเลขสด จากบอร์ดจริงหรือโหมดจำลอง (ไม่ต้องมีบอร์ด) |
| ④ ถาม AI | ถามเรื่องบอร์ด เซนเซอร์ และ **คำสั่ง Arduino เช่น "digitalWrite เขียนใน MicroPython ยังไง"** ถ้าไม่เปิด AI จะตอบจากคลังความรู้และคู่มือคำสั่ง |
| ⑤ คลังความรู้ | ข้อมูลบอร์ด 15 รุ่น อุปกรณ์ 66 ชนิด ขา แรงดัน คำเตือน **คู่มือคำสั่ง Arduino / Turbo C → MicroPython 288 หน้า** **🧮 การ์ดคณิตศาสตร์และตรรกะ 5 ใบ** **⚡ การ์ดพื้นฐานไฟฟ้า 11 ใบ** **เพิ่มอุปกรณ์ใหม่โดยแนบรูปหรือข้อความให้ AI วิเคราะห์ได้** **🎬 บทเรียนภาพเคลื่อนไหว** (ดูข้อ 9) |
| ⚙ ตั้งค่า | ตั้งชื่อ AI ของคุณ ชื่อโรงเรียน และเลือกสมอง AI |

ปุ่ม **▶ รันบนบอร์ด** รันโค้ดทันทีโดยไม่บันทึก เหมาะกับการทดลอง
ปุ่ม **⬆ อัปโหลดเป็น main.py** บันทึกลงบอร์ด เสียบไฟครั้งต่อไปบอร์ดจะทำงานเอง

## 4. สมอง AI (เลือกได้ในแท็บตั้งค่า)

- **ไม่ใช้ AI:** ใช้แม่แบบที่ตรวจแล้ว ทำงานออฟไลน์ ผลแน่นอนทุกครั้ง
- **Claude API:** สมัครที่ console.anthropic.com แล้วนำ API Key มาใส่ ต้องมีอินเทอร์เน็ต มีค่าใช้จ่ายตามการใช้งาน
- **Ollama:** ติดตั้งจาก ollama.com แล้วพิมพ์ `ollama pull qwen2.5-coder:7b` ฟรีและออฟไลน์ แต่ต้องใช้คอมพิวเตอร์สเปกดี

ไม่ว่าเลือกแบบไหน โปรแกรมจะส่งข้อมูลจากคลังความรู้ไปให้ AI ด้วยทุกครั้ง (RAG) และตรวจเลขขาในโค้ดที่ AI เขียนอีกรอบ

## 5. ใส่รูปบอร์ดและอุปกรณ์

**วิธีง่ายที่สุด:** แท็บคลังความรู้ → เลือกอุปกรณ์ → กด "🖼 เพิ่ม / เปลี่ยนรูป" → เลือกรูปจากเครื่อง (ใช้รูป .jpg จากมือถือได้เลย โปรแกรมย่อและแปลงให้)

ถ้ามีรูปหลายรูป ใส่ทีเดียวได้ตามนี้:

1. เปิดไฟล์ `images/รายชื่อรูปที่ต้องถ่าย.txt` ดูชื่อไฟล์ของแต่ละอุปกรณ์
2. ถ่ายรูปด้วยมือถือ แล้วคัดลอกลงโฟลเดอร์ `images` ตั้งชื่อตามรายชื่อ เช่น `hc-sr04.jpg`
3. ดับเบิลคลิก `prepare_images.bat` (หรือพิมพ์ `python prepare_images.py`) โปรแกรมจะย่อรูป แปลงเป็น .png และบอกว่ายังขาดรูปอะไร
4. เปิดโปรแกรมใหม่ รูปจะขึ้นในแท็บคลังความรู้

## 6. เพิ่มอุปกรณ์ใหม่ในคลังความรู้ (แนบรูป / ข้อความ ให้ AI วิเคราะห์)

แท็บคลังความรู้ → กด **"➕ เพิ่มอุปกรณ์ใหม่"** (หรือเลือกอุปกรณ์เดิมแล้วกด **"✏ แก้ไข / ให้ AI วิเคราะห์อุปกรณ์นี้"**)

**ส่วนที่ ① แนบข้อมูลให้ AI**

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| 🖼 เพิ่มรูป | รูปถ่ายอุปกรณ์จริง รูปผังขา (pinout) หรือภาพหน้าจอร้านค้าออนไลน์ แนบได้หลายรูป รูปแรกจะเป็นรูปหลักในคลังความรู้ |
| 📋 วางรูปจากคลิปบอร์ด | คัดลอกรูปจากเว็บหรือโปรแกรมจับภาพหน้าจอ แล้วกดวางได้เลย |
| 📄 เปิดไฟล์ข้อความ / โค้ด / Word | เปิดไฟล์ `.ino` `.py` `.txt` `.md` `.docx` ข้อความจะเข้าไปในช่องข้อความ ถ้าไฟล์ Word มีรูป โปรแกรมจะถามว่าจะแนบรูปให้ AI ด้วยไหม |
| ช่องข้อความ | พิมพ์หรือวางอะไรก็ได้ เช่น ชื่อรุ่น รายละเอียดจากร้าน datasheet หรือโค้ดตัวอย่าง Arduino |

แล้วกด **"🤖 ให้ AI วิเคราะห์และกรอกฟอร์ม"** AI จะ

1. อธิบายว่าอุปกรณ์คืออะไร ทำงานอย่างไร ต่อสายอย่างไร ค่าที่อ่านได้หมายถึงอะไร ไอเดียโปรเจกต์ และข้อควรระวัง
2. แปลงโค้ด Arduino เป็น MicroPython แล้วกรอกฟอร์มส่วนที่ ② ให้ตามรูปแบบของโปรแกรม (ขา โค้ดตั้งค่า โค้ดอ่านค่า ค่าจำลอง ที่อยู่ I2C)
3. โปรแกรมทดลองสร้างโค้ดทันที ถ้าไม่ผ่าน จะส่งข้อผิดพลาดกลับไปให้ AI แก้เองอีก 1 รอบ

- **Claude** อ่านได้ทั้งรูปและข้อความ
- **Ollama** อ่านรูปได้เฉพาะโมเดลที่รองรับภาพ เช่น `qwen2.5vl` หรือ `llava` ถ้าโมเดลอ่านรูปไม่ได้ โปรแกรมจะวิเคราะห์จากข้อความอย่างเดียวและแจ้งให้ทราบ
- **ไม่ใช้ AI:** กด **"🔎 วิเคราะห์แบบไม่ใช้ AI"** โปรแกรมอ่านโค้ด Arduino/MicroPython หาขาแอนะล็อก ขาดิจิทัล I2C หรือ 1-Wire แล้วกรอกฟอร์มเป็นแบบร่างให้ และบอกว่าอุปกรณ์ในข้อความมีในคลังแล้วหรือยัง (อ่านรูปไม่ได้)

**ส่วนที่ ② ตรวจฟอร์ม** → กด "🧪 ทดลองสร้างโค้ด" ดูโค้ดและการต่อสาย → กด "💾 บันทึก"
โปรแกรมเก็บรูปที่แนบ ข้อความประกอบ และผลการวิเคราะห์ของ AI ไว้กับอุปกรณ์ ดูได้ในแท็บคลังความรู้
ถ้าโค้ดที่ได้ยังผิด โปรแกรมจะไม่ยอมบันทึก คลังความรู้จึงไม่เสีย

> ขาที่ต้องการตั้งชื่อในโค้ดเอง เขียนต่อท้ายด้วย `@ชื่อ` เช่น `AO=signal:adc@SIG` แล้วในโค้ดใช้ `{SIG}` / `{ADC_SETUP_SIG}` / `adc_SIG`

หรือแก้ไฟล์ `knowledge/components.json` เพิ่มอุปกรณ์ 1 ชุด ช่องสำคัญ:

| ช่อง | ความหมาย |
|---|---|
| `keywords` | คำที่นักเรียนอาจพิมพ์ เช่น `["servo", "เซอร์โว"]` |
| `type` | `sensor` (อ่านค่า), `actuator` (สั่งงาน), `display` (จอ), `info` (มีแค่ข้อมูล) |
| `pins` | ขาของอุปกรณ์ `kind` = `power5`, `power3`, `gnd`, `signal` และ `need` = `out`, `inp`, `adc`, `pwm`, `i2c_sda`, `i2c_scl` |
| `setup`, `read`, `on`, `off` | โค้ด MicroPython ใช้ `{SIG}` แทนเลขขา โปรแกรมจะเลือกขาให้เอง |
| `keys` | ชื่อค่าที่ print ออกมา ใช้ทำกราฟเรียลไทม์ |
| `warnings` | คำเตือนที่ต้องแสดงทุกครั้ง |

แล้วรัน `py -3 test_generator.py` เพื่อตรวจว่าโค้ดที่สร้างยังถูกต้อง

### เพิ่มโปรเจกต์ในคลังโปรเจกต์

แก้ไฟล์ `knowledge/projects.json` แต่ละโปรเจกต์มี `name_th`, `desc_th`, `level` (ง่าย/กลาง/ยาก), `category`, `command` (คำสั่งภาษาไทยที่มีชื่ออุปกรณ์) และ `components`
แนวคิดโปรเจกต์หลายชิ้นดัดแปลงจากรายชื่อโปรเจกต์เซนเซอร์ของ Nevonprojects ให้เหมาะกับอุปกรณ์ในชุดเรียน (ช่อง `inspired_by`)

| MPU6050 (มีเดิม) | แปรงสีฟัน | accel_x/y/z | แปรงสีฟันอัจฉริยะ |

บอร์ดใหม่: **ESP32-CAM (AI-Thinker)** — ตัวอย่างโค้ดสตรีมภาพอยู่ใน "โค้ดของฉัน" (`my_code/esp32_cam_stream.ino`) ใส่ชื่อและรหัส Wi-Fi ก่อนอัปโหลดด้วย Arduino IDE

⚠ อุปกรณ์กลุ่มนี้ใช้เพื่อการเรียนรู้ ไม่ใช่เครื่องมือแพทย์ ห้ามนำหัววัด pH เข้าปาก และ ECG/EEG ต้องใช้ไฟจากแบตเตอรี่หรือโน้ตบุ๊กที่ถอดสายชาร์จเท่านั้น

## 8. ตัวอย่าง Arduino และคู่มือคำสั่ง (เพิ่มในเวอร์ชัน 2.3)

ข้อมูลชุดนี้คัดมาจาก Arduino IDE 3 ชุดที่ครูส่งมา (1.5.3 ของ Intel Galileo ทั้งชุดย่อและชุดเต็ม และ 1.6.0 + Intel)
ส่วนที่เป็นของบอร์ด Intel Galileo / Edison (เลิกผลิตแล้ว รัน MicroPython ไม่ได้) และไฟล์โปรแกรม IDE ไม่ได้นำมาใช้

### 8.1 คลังตัวอย่าง Arduino (ปุ่ม 📚 ตัวอย่าง Arduino ในแท็บ ① สร้างโค้ด)

- ตัวอย่าง **98 แบบ** จาก Arduino IDE 1.6.0 บวกหมวดที่เขียนเพิ่ม (15 หุ่นยนต์, 16 เกษตร, 17 Turbo C, 18 มือหุ่นยนต์, 19 พื้นฐานไฟฟ้า) **รวม 127 แบบ มีโค้ด MicroPython 57 แบบ** (พื้นฐาน ขาดิจิทัล แอนะล็อก เซนเซอร์ Starter Kit ฯลฯ) และไลบรารี Servo, LiquidCrystal, Stepper, EEPROM มีชื่อและคำอธิบายภาษาไทย แบ่งระดับ ง่าย / กลาง / ยาก
- **28 แบบมีโค้ด MicroPython ที่แปลงแล้ว (🐍)** เช่น Blink, Fade, Button, Debounce, Ping (อัลตราโซนิก), Knock, Servo Sweep/Knob, เครื่องดนตรีแสง, นาฬิกาทรายดิจิทัล
  - เปิดแล้วโปรแกรม **เลือกขาให้ตรงกับบอร์ดที่เลือก** (ESP32 ทุกรุ่น, Pico, ESP8266) พร้อม **ภาพการต่อสาย** และ **กราฟเรียลไทม์**
  - ถ้าเปลี่ยนบอร์ด ให้เปิดตัวอย่างใหม่อีกครั้ง
  - บอร์ดที่มีขาน้อย (KidBright32, ESP32-CAM, ESP8266) บางตัวอย่างต้องใช้ LED หลายดวง โปรแกรมจะแจ้งว่าขาไม่พอ
- ตัวอย่างที่ยังไม่มีโค้ด MicroPython เปิดเป็นโค้ด C++ ต้นฉบับได้ และโปรแกรมจะแสดง **ตารางคำสั่งในโค้ดนั้นพร้อมวิธีเขียนใน MicroPython** ให้นักเรียนลองแปลงเอง
- ไฟล์อยู่ในโฟลเดอร์ `arduino_examples/<หมวด>/<ชื่อ>/` เปิดไฟล์ `.ino` ด้วย Arduino IDE ได้โดยตรง

### 8.2 คู่มือคำสั่ง Arduino → MicroPython (แท็บ ⑤ คลังความรู้)

- เลือก "คำสั่ง Arduino → MicroPython" ในช่องใต้ช่องค้นหา หรือพิมพ์ชื่อคำสั่ง เช่น `millis`, `analogWrite` หรือคำไทย เช่น `หน่วงเวลา`, `เซอร์โว`
- **130 คำสั่งหลักมีคำอธิบายไทย โค้ด MicroPython ที่ใช้แทน และข้อควรระวัง** (📘) อีก 149 หน้าเป็นคู่มือต้นฉบับภาษาอังกฤษ (📄)
- ปุ่ม "ใช้อุปกรณ์นี้ในคำสั่ง / คัดลอกโค้ดคำสั่ง" คัดลอกโค้ด MicroPython ไปวางในช่องโค้ดได้
- เปิดไฟล์ `.ino` ใด ๆ ในแท็บ ① โปรแกรมจะบอกว่าคำสั่งในไฟล์เขียนใน MicroPython อย่างไร
- เวลาถาม AI หรือให้ AI วิเคราะห์อุปกรณ์ใหม่ โปรแกรมแนบคู่มือส่วนที่เกี่ยวข้องไปด้วย ทำให้ AI แปลงโค้ด Arduino ได้แม่นขึ้น
- ที่มา: Arduino Language Reference (CC BY-SA 3.0) เก็บในไฟล์ `knowledge/arduino_reference.json`

ตรวจกับไฟล์ `pins_arduino.h` ของ Arduino IDE 1.6.0 แล้วแก้ข้อมูลใน `knowledge/boards.json`

### 8.4 สำหรับผู้พิการทางการได้ยิน

- **คู่มือภาพ 15 ภาพ (อัปเดตเป็น 2.7.1)** ในโฟลเดอร์ `คู่มือภาพ/` (PNG ขนาด A4 และ PDF รวมเล่มสำหรับพิมพ์) ใช้ภาพหน้าจอจริงของเวอร์ชันนี้ มีเลขขั้นตอนและกรอบแดงชี้จุดที่ต้องกด ประโยคสั้น ไม่มีข้อมูลที่ต้องฟัง ครอบคลุม: ติดตั้ง/อัปเดต/เจอ Error, เปิดตัวอย่าง, ต่อสาย, ภาพการทำงาน, ตัวเลขและกราฟ, หาคำสั่ง, ถาม AI, 🩺 แก้โค้ดที่ผิด, รูปอุปกรณ์, พื้นฐานไฟฟ้า, มือหุ่นยนต์ (ต่อสาย / ใช้กล้อง), ขาจอ OLED และ "ไม่ได้ยินเสียง? ใช้ตาแทน"
- **ลง MicroPython:** เดิมโปรแกรมส่งเสียงบี๊บตอนต้องกดปุ่ม BOOT ตอนนี้กรอบข้อความจะ**กะพริบสีแดงสลับส้ม**ด้วย จนกว่าจะเปลี่ยนเป็นสีเขียว
- **ตรวจการต่อสาย (ขั้นที่ 5):** ตอนถามว่าบัซเซอร์ดังเป็นจังหวะไหม จะมีคำแนะนำให้ "เอานิ้วแตะบัซเซอร์ จะรู้สึกสั่นเป็นจังหวะ"
- **แท็บ ④ ถาม AI:** แก้ปัญหาช่องพิมพ์คำถามหายไปจากจอเมื่อหน้าต่างเตี้ย (ช่องพิมพ์อยู่ล่างสุดเสมอ)
- **ภาพการทำงาน (แท็บ ②):** บัซเซอร์มีคลื่นเสียงวิ่งและคำว่า "สั่น / ดัง" แถบบนสุดเขียนเป็นประโยคให้อ่าน
- **มือหุ่นยนต์:** ปุ่มหยุดฉุกเฉินสีแดง และมือกางเองเมื่อสัญญาณหาย ไม่ต้องอาศัยเสียงเตือน
- แนะนำครู: ให้นักเรียนต่อ LED คู่กับบัซเซอร์เสมอ และดูค่าเซนเซอร์เสียงจากกราฟในแท็บ ③

## 9. หุ่นยนต์บีมและบทเรียนภาพเคลื่อนไหว (เพิ่มในเวอร์ชัน 2.4)

ข้อมูลชุดนี้มาจากใบงาน **IT Line Tracker Robot** (โครงการพัฒนาทักษะด้านอิเล็กทรอนิกส์และการเขียนโปรแกรมคอมพิวเตอร์) และภาพเคลื่อนไหวขั้นตอนการประกอบที่ครูส่งมา
หุ่นยนต์บีมเดินตามเส้นด้วยวงจรทรานซิสเตอร์ล้วน ไม่ต้องเขียนโปรแกรม เวอร์ชันนี้จึงใช้เป็น **บทเรียนก่อนเขียนโปรแกรม** แล้วต่อยอดให้หุ่นตัวเดิมเขียนโปรแกรมได้

### 9.1 บทเรียนภาพเคลื่อนไหว (แท็บ ⑤ คลังความรู้)

- เลือก **🎬 ประกอบหุ่นยนต์บีมเดินตามเส้น** ในรายการ (หรือเลือก "🎬 บทเรียนภาพเคลื่อนไหว" ในช่องใต้ช่องค้นหา) แล้วกดปุ่ม **"🎬 เปิดบทเรียนภาพเคลื่อนไหว"**
- เปิดในเว็บเบราว์เซอร์ ไม่ต้องใช้อินเทอร์เน็ต มี 39 ขั้น: บัดกรีแผงเซนเซอร์ → บัดกรีสายมอเตอร์ → ต่อวงจรล้อขวา (1–15) → ล้อซ้าย (16–31) → ทดสอบ → ประกอบตัวรถ
- ทุกขั้นมีตัวอักษรกำกับและกรอบกะพริบชี้รูที่ต้องเสียบ ไม่มีข้อมูลที่ต้องฟัง จึงใช้กับนักเรียนที่มีความบกพร่องทางการได้ยินได้
- เลือกอุปกรณ์ในหมวด "หุ่นยนต์บีม" แล้วกดปุ่มเดียวกันก็เปิดบทเรียนได้ ในผู้ช่วยนำทางขั้นที่ 2 โปรเจกต์หมวดหุ่นยนต์มีลิงก์ "🎬 ดูบทเรียนภาพเคลื่อนไหว"
- ครูเพิ่มบทเรียนเองได้: วางไฟล์ `.html` ในโฟลเดอร์ `lessons/` แล้วเพิ่มรายการในไฟล์ `lessons/index.json`

### 9.2 ชิ้นส่วนอิเล็กทรอนิกส์ในคลังความรู้ (หมวด "หุ่นยนต์บีม")

| อุปกรณ์ | สิ่งที่นักเรียนได้เรียน |
|---|---|
| หุ่นยนต์บีมเดินตามเส้น | หลักการทำงาน เส้นทางสัญญาณ รายการอุปกรณ์ 18 รายการ และวิธีเปลี่ยนเป็นหุ่นเขียนโปรแกรม |
| BC337 / BD679 | วิธีหันตัวถังและลำดับขา (BC337 = C B E, BD679 = B C E ต่างกัน ระวังสลับ) |
| ไดโอด 1N4001 | แถบสีขาว = ขั้วลบ ทำไมต้องต่อคร่อมมอเตอร์ (กันไฟย้อน) |
| ตัวเก็บประจุ 0.1µF (104) | อ่านรหัส 104 และหน้าที่ลดสัญญาณรบกวนจากมอเตอร์ |
| ตัวต้านทาน | อ่านแถบสี 100Ω / 220Ω / 1kΩ / 10kΩ |
| มอเตอร์เกียร์ TT, รังถ่าน, บอร์ดทดลอง | รูไหนเชื่อมกัน การอ่านชื่อรูอย่าง g14 ข้อควรระวังเรื่องไฟ |

- ชิ้นส่วนกลุ่มนี้ไม่ต้องเขียนโปรแกรม ถ้าพิมพ์ชื่อ เช่น "BC337" ในแท็บ ① โปรแกรมจะบอกว่าดูวิธีต่อได้ที่ไหน แทนการสร้างโค้ดที่ไม่เกี่ยวข้อง
- ถามในแท็บ ④ ได้ เช่น "BD679 ขาไหนเป็นขา B" (ตอบได้แม้ไม่เปิด AI)
- **แก้ข้อผิดพลาดในใบงานต้นฉบับ:** ขั้นตอนที่ 21 พิมพ์ว่าต่อ a18 ไป "ไฟบวก (+)" ที่ถูกคือ **ไฟลบ (−)** เพราะขา E ของ BD679 ต้องลงกราวด์ เหมือนขั้นตอนที่ 6 (ภาพเคลื่อนไหวแก้ไว้แล้ว)

### 9.3 ต่อยอด: หุ่นยนต์บีมที่เขียนโปรแกรมได้

อุปกรณ์ใหม่ 2 ชนิดที่ใช้ของเดิมจากหุ่นบีม ใช้กับตัวสร้างโค้ด ภาพการต่อสาย กราฟ และการตรวจสายได้ครบ

- **แผงเซนเซอร์หุ่นบีม** (พิมพ์ "เซนเซอร์หุ่นบีม") อ่านค่าแสงสะท้อน 0–100 พื้นขาว = ค่าสูง เส้นดำ = ค่าต่ำ
- **วงจรขับมอเตอร์หุ่นบีม** (พิมพ์ "มอเตอร์หุ่นบีม") บอร์ดส่งสัญญาณ PWM เข้าแถว 10 ผ่าน 1kΩ เดิม ไปขับ BC337 + BD679 มอเตอร์ยังใช้ถ่าน 4.5V

ตัวอย่างใหม่ใน **📚 ตัวอย่าง Arduino → หมวด 15 หุ่นยนต์** (มีทั้ง MicroPython และ C++ สำหรับ Arduino Uno)

| ตัวอย่าง | ระดับ | ทำอะไร |
|---|---|---|
| BeamSensorRead | ง่าย | ดูค่าเซนเซอร์ซ้าย/ขวาเป็นกราฟ หาค่าพื้นขาวกับเส้นดำ |
| BeamLineFollower | กลาง | หุ่นบีมเขียนโปรแกรมได้ กฎเดียวกับหุ่นบีม แล้วมีโจทย์ให้ลองปรับให้เก่งขึ้น 3 ข้อ |
| LineFollowerL298N | ยาก | ทางเลือกสำหรับโรงเรียนที่มีโมดูล TCRT5000 + L298N วิ่งตรง เลี้ยว และหยุดที่เส้นชัย |

**วิธีแปลงหุ่นบีม (ถอดถ่านก่อนทุกครั้ง)**

1. ถอดสายขาวของเซนเซอร์ออกจากแถว 10 และย้ายสายตัวต้านทานปรับค่าได้ที่อยู่ในแถว 10 ไปแถวว่าง (เช่น แถว 5) เสียบสายขาวไว้แถวเดียวกัน แล้วต่อจากแถวนั้นไปขา ADC ของบอร์ด
2. ย้ายสาย + (สีเขียว) ของแผงเซนเซอร์ไปขา **3V3** ของบอร์ด (ห้ามใช้ไฟถ่าน 4.5V แรงดันจะเกินขา ADC ของ ESP32 / Pico)
3. ต่อสายจากขา PWM ของบอร์ดเข้าแถว 10
4. ต่อ GND ของบอร์ดเข้ารางไฟลบของบอร์ดทดลอง
5. ทำเหมือนกันอีกข้าง แล้วเปิดตัวอย่าง BeamSensorRead หาค่า THRESHOLD ก่อนใช้ BeamLineFollower

โปรเจกต์ใหม่ในผู้ช่วยนำทาง (หมวดหุ่นยนต์): "อ่านค่าเซนเซอร์หุ่นยนต์บีม" และ "หุ่นยนต์บีมเขียนโปรแกรมได้ (ทีละล้อ)"

## 10. เกษตรอัจฉริยะและสถานีวัดอากาศ (เพิ่มในเวอร์ชัน 2.5)

ข้อมูลจากงานอบรมโครงการพัฒนาทักษะด้านสะเต็มและโค้ดดิ้งแก่เยาวชนในชนบท (ทสรช. 25–27 ก.ย.) 24 โครงงาน และรูปสถานีวัดอากาศที่ครูส่งมา

### 10.1 อุปกรณ์ใหม่ในคลังความรู้

| อุปกรณ์ | พิมพ์ในคำสั่งว่า | ค่าที่อ่านได้ |
|---|---|---|
| เซนเซอร์ EC (ค่าปุ๋ยในน้ำ) | ค่า EC, ค่าปุ๋ย | ec 0-100 (ค่าเทียบ) |
| เซนเซอร์ออกซิเจนละลายน้ำ DO | ค่า DO, ออกซิเจนละลายน้ำ | do_mv (มิลลิโวลต์) |
| เซนเซอร์ความขุ่นของน้ำ | น้ำขุ่น, ความขุ่น | turbidity 0-100 |
| เครื่องวัดปริมาณน้ำฝนแบบถังกระดก | วัดปริมาณน้ำฝน | rain_mm (นับด้วยอินเทอร์รัปต์ ไม่นับซ้ำ) |
| โมดูลนาฬิกา RTC DS3231 | DS3231, rtc | ตรวจบน I2C |
| สถานีวัดอากาศ (มีรูปจริง 2 รูป), GPS NEO-6M, เซนเซอร์สี TCS3200, ปั๊มรีดท่อ, จอ LCD แบบต่อขาตรง | ชื่ออุปกรณ์ | ข้อมูลและวิธีต่อ (ไม่ต้องสร้างโค้ด) |

- **สถานีวัดอากาศ:** อธิบายส่วนประกอบในรูป (กรวยรับน้ำฝน ถังกระดก โล่กันแดดสีขาว แผงโซลาร์) วิธีตั้ง และวิธีทำโล่กันแดดเองจากจานรองกระถาง
- **แก้ตัวสร้างโค้ด:** "ถ้า DHT22 ความชื้นน้อยกว่า 80" เดิมเพิ่ม DHT11 มาอีกตัวและเช็กอุณหภูมิแทนความชื้น ตอนนี้เลือกค่าที่พูดถึงหลังคำว่า "ถ้า" ได้ถูกต้อง

### 10.2 คลังโปรเจกต์หมวด "เกษตรอัจฉริยะ" 17 แบบ

โรงเรือนเห็ด, โรงเรือนเกษตร, ฟาร์มวัว, สวนผักแนวตั้ง, สวนทุเรียน, ตู้จิ้งหรีด, เรือตรวจคุณภาพน้ำ, หุ่นไล่กา, อควาโปนิกส์, มะเขือเทศ, ฟาร์มวิจัย, ตู้ฟักไข่, เครื่องผสมปุ๋ย, ฟาร์มไก่, บ่อกุ้ง, ระบบควบคุมน้ำ และสถานีวัดปริมาณน้ำฝน (ช่อง `inspired_by` บอกชื่อโครงงานและโรงเรียนเจ้าของ)

### 10.4 🩺 ตรวจโค้ดหาจุดที่มักเขียนผิด

เปิดไฟล์ .ino หรือ .c ในแท็บ ① โปรแกรมจะตรวจให้อัตโนมัติ (แสดงเป็นสีแดง/ส้มในช่องคำเตือน)

- **ใช้ขาเดียวกันกับหลายอุปกรณ์** (รวมขาของ LiquidCrystal, HX711, SoftwareSerial, Servo) — พบจริงในเครื่องผสมปุ๋ยและโรงเรือนมะเขือเทศ
- ประกาศขาไว้แต่ไม่ได้ใช้, อ่าน DHT ไม่ตรวจ isnan(), hour() == 8 ทำซ้ำทั้งชั่วโมง, minute() == 0 กับ delay ยาว, delay นานเกิน 10 วินาที
- pulseIn ไม่มีเวลารอ, อัลตราโซนิกวัดระดับน้ำกลับด้าน, ความชื้นดินกลับด้าน, pH/DO ยังเป็นโวลต์, TCS3200 อ่านด้วย analogRead, lcd.print ไม่ setCursor, HX711 ไม่ปรับเทียบ, รีเลย์ Active LOW
- ครูใช้ตรวจงานนักเรียนได้: ให้นักเรียนส่งไฟล์ .ino แล้วเปิดดูคำเตือน
- **ไฟล์ฝึก (2.7.1):** `my_code/ฝึกหาจุดผิด_รดน้ำต้นไม้.ino` มีจุดผิด 5 จุด ให้นักเรียนเปิดแล้วแก้ตามข้อความ 🩺 (เฉลยอยู่ท้ายไฟล์ และในคู่มือภาพที่ 9)

## 11. จาก Turbo C พอร์ตขนาน สู่ MicroPython (เพิ่มในเวอร์ชัน 2.5)

จากคลังงานสอน Turbo C เดิมของครู (tc.zip) โครงงานที่คุมฮาร์ดแวร์ผ่านพอร์ตขนาน `outport(0x378, ค่า)` / `inportb(0x379)`

- **คลังความรู้ → "พอร์ตขนาน (LPT1)"** ตารางขา DB25 ทุกขา ค่าบิต และวิธีย้ายแต่ละขามาต่อที่บอร์ด

| LptLedMotor | testoutportLed.c / testoutportMotor.c | ง่าย |

## 13. รูปวาดอุปกรณ์และภาพการทำงานของโครงงาน (เพิ่มในเวอร์ชัน 2.6)

### 13.1 รูปวาดอุปกรณ์

- อุปกรณ์ทั้ง 66 ชนิดในคลังความรู้มีรูปวาดแล้ว (2.7 เพิ่มมือหุ่นยนต์และ Raspberry Pi 5) (LED มีขายาว/ขาสั้น, เซอร์โวมีแขน, DHT22 กล่องขาวมีตะแกรง, รีเลย์, หัววัด pH/EC/DO, เครื่องวัดน้ำฝน, พอร์ตขนาน ฯลฯ)
- วาดด้วยโค้ดทั้งหมด ไม่ใช้ไฟล์รูป จึงไม่มีปัญหาลิขสิทธิ์ ย่อ/ขยายได้ และใช้ได้ทุกเครื่อง
- แสดงใน: ภาพการต่อสาย (ในกล่องอุปกรณ์), ผู้ช่วยนำทางขั้นที่ 3 และ 4, และแท็บ ⑤ คลังความรู้ (เมื่อยังไม่มีรูปถ่าย ถ้าใส่รูปถ่ายแล้วจะใช้รูปถ่าย)
- รูปขยับตามการทำงาน: LED สว่าง, บัซเซอร์มีคลื่นเสียง, เซอร์โวหมุนแขน, มอเตอร์/ล้อหมุน, PIR เรืองแสงเมื่อเจอคน, ไฟ RGB เปลี่ยนสี

### 13.2 ภาพการทำงานของโครงงาน

แท็บ ② → ปุ่ม **"🎞 ภาพการทำงานของโครงงาน"** (หรือผู้ช่วยนำทางขั้นที่ 6 → "🎞 ดูภาพการทำงาน")

| ช่อง | แสดงอะไร |
|---|---|
| ① สิ่งที่เซนเซอร์วัด | ภาพของจริงที่เปลี่ยนตามค่า เช่น ดินแห้งสีอ่อนและใบไม้เหี่ยว / ดินเปียกสีเข้ม, เทอร์โมมิเตอร์, ท้องฟ้ากลางวัน/กลางคืน, วัตถุเลื่อนใกล้-ไกล, คนเดินเข้ามา, ถังน้ำ, ฝนตก, บีกเกอร์เปลี่ยนสีตาม pH, ฟองออกซิเจน, น้ำขุ่น ฯลฯ พร้อมรูปเซนเซอร์ แถบค่า และตัวเลข |
| ② บอร์ดคิดตามโค้ด | เงื่อนไขเป็นภาษาไทย เช่น "ถ้า ความชื้นในดิน น้อยกว่า 35 % → ให้ ปั๊มน้ำ ทำงาน" และบอกว่า **ตอนนี้จริงหรือไม่** (กรอบเขียว/แดง) |
| ③ อุปกรณ์ทำงาน | รูปอุปกรณ์ + ผลที่เกิดขึ้น เช่น น้ำพ่นลงต้นไม้, พัดลมหมุน, พ่นหมอก, ฟองอากาศจากเครื่องตีน้ำ, ไฟกกให้ความร้อน, บัซเซอร์ "สั่น / ดัง", ไม้กั้นยกขึ้น, ล้อหมุน |

- **โปรแกรมสร้างภาพเองจากคำสั่ง** จึงใช้ได้กับทุกโปรเจกต์ ทุกตัวอย่าง และคำสั่งที่พิมพ์เอง รีเลย์จะรู้ว่าต่อกับอะไรจากคำในคำสั่ง (ปั๊ม พัดลม พ่นหมอก ไฟกก เครื่องตีน้ำ หลอดไฟ)
- ใช้ค่าจำลอง (กด "⚡ ดูการทำงาน (จำลอง)") หรือค่าจริงจากบอร์ด (รันบนบอร์ดจริง) จุดข้อมูลวิ่งจากเซนเซอร์เข้าบอร์ด และจากบอร์ดไปอุปกรณ์เมื่อสั่งงาน
- **ลากแถบค่าใต้รูปเซนเซอร์เพื่อทดลองเอง** เช่น ลากความชื้นดินลงต่ำกว่า 35 แล้วดูปั๊มทำงาน กด "↺ ให้ค่าเปลี่ยนเอง" เพื่อกลับไปใช้ค่าจำลองอัตโนมัติ (ใช้ได้เฉพาะโหมดจำลอง)
- แถบคำบรรยายด้านบนเขียนเป็นประโยค เช่น "เซนเซอร์วัดได้ ความชื้นในดิน = 12 % → เงื่อนไขเป็นจริง → ปั๊มน้ำ ทำงาน" ทุกอย่างมีตัวอักษรกำกับ ไม่มีข้อมูลที่ต้องฟัง เหมาะกับนักเรียนที่มีความบกพร่องทางการได้ยิน

## 14. มือหุ่นยนต์ AI และหลักสูตรควบคุมแขนกลระยะไกล (เพิ่มในเวอร์ชัน 2.7)

ต่อยอดจากโค้ดมือหุ่นยนต์ของครู (`pan_robot_hand2.ino`) หน้าเว็บกล้องอ่านมือ และเอกสารหลักสูตร 30 ชั่วโมง

### 14.1 สิ่งที่แก้จากไฟล์ต้นฉบับ (สำคัญ)

- **หน้าเว็บกับโค้ดบอร์ดพูดคนละภาษา**: หน้าเว็บเดิมส่ง `A:0,180,...` (0-180 องศา) แต่โค้ด Arduino รอรับ `T:45` หรือ `ALL:T45,I30,...` (0-90 องศา) **มือจึงไม่ขยับเลย** เวอร์ชันนี้แก้ทั้งสองฝั่งให้ตรงกัน: บอร์ดรับได้ทั้งสองแบบ และหน้าเว็บเลือกได้ว่าจะส่งแบบไหน (ค่าเริ่มต้น ALL)
- เพิ่ม **ปุ่มหยุดฉุกเฉิน (STOP / RESUME)**, **Fail-safe**: ถ้าไม่ได้รับคำสั่งหรือสัญญาณ HB เกิน 3 วินาที (สาย USB) หรือ 1 วินาที (Wi-Fi) มือจะกางออกเอง, ไม่เห็นมือในกล้อง 1.5 วินาที ส่ง OPEN
- ตรวจนิ้วโป้งด้วยระยะทาง จึงใช้ได้ทั้งมือซ้ายและมือขวา
- ไฟล์ต้นฉบับของครูเก็บไว้ไม่แก้ไขที่ `arduino_examples/18.RobotHand/RobotHandSerial/pan_robot_hand2_original.ino`
